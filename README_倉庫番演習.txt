# 倉庫番（Sokoban Game）

## ゲームの概要

Python で作成したコンソール版の倉庫番（Sokoban）ゲームです。全4ステージ構成で、プレイヤーを操作してすべての箱（`$`）をゴール（`.`）に押し込むとステージクリアになります。手数制限やアンドゥ・リスタート、手数切れ時のゲームオーバー＆自動リスタート機能を追加しています。

## 動作環境

- OS：Windows / macOS / Linux（自分の環境に合わせて書き換える）
- Python：Python 3.10 以上（`python --version` で確認したバージョンに書き換える）
- 必要なライブラリ：追加ライブラリ不要（Python 標準ライブラリのみで動作）

## インストール方法

リポジトリをクローンまたはダウンロードし、`sokoban_demo.py` があるフォルダに移動します。追加パッケージのインストールは不要です。

```bash
git clone [https://github.com/bihaimucun-oss/sokoban_game.git](https://github.com/bihaimucun-oss/sokoban_game.git)

操作方法
w / a / s / d（または実装している移動キー）：プレイヤーの上下左右移動・箱押し

u：1手戻す（Undo）

r：現在のステージをリスタート

q：ゲームを終了

ルール・クリア条件・ゲームオーバー
すべての箱をゴールに配置するとステージクリアとなり、次のステージへ進みます。全4ステージをクリアすると全ステージクリアとなります。

各ステージには最大手数（20, 35, 50, 65）が設定されており、画面に現在の移動回数と残り手数が表示されます。

クリアせずに最大手数に達するとゲームオーバーとなり、そのステージを最初からやり直します。

追加・改良した機能
改良機能01：手数制限と残り手数表示
各ステージに最大手数（MAX_MOVES：[20, 35, 50, 65]）を設定し、load_level・draw_game・main を更新しました。プレイ中に現在の移動回数と残り手数が表示されます。

改良機能02：ステージ追加と難易度調整
LEVELS を全4ステージに拡張し、ステージごとの難度に合わせて最大手数（20, 35, 50, 65）を調整しました。

改良機能03：手数切れ時のゲームオーバー＆自動リスタート
クリアせずに移動回数が最大手数に達した場合、main ループでゲームオーバーメッセージを表示し、現在のステージを自動でやり直す処理を実装しました。
